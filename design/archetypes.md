# Archetype ideas

Build directions a player could aim for by combining skills and attribute rewards.

| archetype | core | notes |
|---|---|---|
| basic warrior | attacks, damage, hp, block | the straightforward melee build |
| on hit | attack speed, on-hit damage, on-hit status | low attack scaling, some magic power scaling |
| mixed warrior | attack + magic power, attack speed + cast speed | uses attacks and spells together |
| mage | magic power, cast speed, spells | |
| assassin | increased damage at the start of the fight | |
| buffs | warrior with self-buff spells | |
| debuffs | mage with debuff spells | |
| berserker | takes increased damage, deals increased damage | |
